Quoth packages

Signed APT and Flatpak repositories for Quoth, free software under GPL-3.0-or-later.

Source code

The source of each release served here is attached to that release at https://github.com/abullard1/Quoth/releases/tag/vVERSION. quoth-sources.flatpak is the Flatpak's complete Corresponding Source: every module it bundles, with its patches. quoth-deb-sources.tar.gz is the unmodified source of the wl-clipboard, ydotool and ThorVG the .deb bundles, at their pinned commits, with the wayland-protocols files wl-clipboard's build generates code from. quoth-VERSION.tar.gz is Quoth's own source. The .deb names the sources of the components it bundles in /usr/share/doc/quoth/copyright.

Latest release: Quoth 0.1.0.
